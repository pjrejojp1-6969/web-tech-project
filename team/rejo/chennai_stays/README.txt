# ChennaiStay — Airbnb-style demo

Open `index.html` in a browser.

Features:
- 100 demo rental properties
- 10 Chennai locations: Anna Nagar, Adyar, Besant Nagar, T. Nagar, Velachery, OMR, Nungambakkam, Mylapore, ECR, Porur
- Every listing has a property image URL, rating, reviews, price, owner name and fictional phone number
- 10+ navigable pages/sections
- Search, filters, sorting
- Property detail pages
- Favorites saved in localStorage
- Demo reservations saved in localStorage
- Trips/cancellation
- Host listing form
- Login demo
- Help/FAQ
- Pricing and experiences pages
- Responsive mobile layout

IMPORTANT:
All owner contact details are fictional demo data. Replace them with verified, consented owner information before publishing.
The image URLs are remote demo image URLs, so internet access is needed for images to load.

CUSTOM BACKGROUND:
The uploaded mountain image is included as background.jpg and is used across the site and the home hero.
