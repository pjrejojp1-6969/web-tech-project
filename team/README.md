# Team Project Folder Structure

Use this folder layout for your individual contributions.

```text
team/
├── member-1/
│   ├── gym-landing-page/
│   │   ├── index.html
│   │   ├── style.css
│   │   └── script.js
│   ├── portfolio-showcase/
│   │   ├── index.html
│   │   ├── style.css
│   │   └── script.js
│   └── ...
├── member-2/
│   ├── saas-dashboard/
│   │   ├── index.html
│   │   ├── style.css
│   │   └── script.js
│   └── ...
├── member-3/
│   └── ...
└── member-4/
    └── ...
```

Each project should contain its own independent files and can be completely different from the others.
