# Web Tech Project

This repository is a collaborative UI template collection for a hackathon project. The goal is to create a publicly hosted gallery of reusable UI ideas and templates using GitHub Pages.

## Live Demo

The site is deployed through GitHub Pages and updates whenever changes are merged into the `main` branch.

## Project Structure

- `index.html` – the main landing page for the collection
- `style.css` – shared styling and layout
- `script.js` – small JavaScript interactions

## Team Workflow

1. Fork the repository
2. Create a feature branch
3. Add a topic folder or page component
4. Push to your fork
5. Open a pull request back to `main`

## Local Preview

Open `index.html` in a browser or run a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
